# پنل مدیر: تغییر رمز و حذف حساب

این قابلیت‌ها در پنل مدیر کنار اطلاعات هر شرکت‌کننده اضافه شده‌اند.

## قابلیت‌ها
- تغییر رمز عبور حساب شرکت‌کننده از طریق Supabase Auth Admin API.
- حذف دائمی حساب شرکت‌کننده، پروفایل و گزارش‌های روزانه‌اش در یک تراکنش.
- جلوگیری از حذف حساب مدیر واردشده یا حساب‌های دیگر با نقش admin.
- بررسی نقش مدیر در سرور؛ کنترل‌های رابط کاربری به‌تنهایی مرز امنیتی نیستند.
- کلید `service_role` فقط در محیط Edge Function استفاده می‌شود و هرگز در `index.html` قرار نمی‌گیرد.

## راه‌اندازی

1. ابتدا نسخه پشتیبان Supabase را بگیر.
2. مطمئن شو مهاجرت کامل `supabase/security_hardening.sql` روی همان پروژه اجرا شده است؛ این فایل تابع `c90_admin_delete_user(uuid)` را ایجاد می‌کند.
3. از ریشه مخزن با Supabase CLI وارد پروژه شو:
   `supabase login`
   `supabase link --project-ref YOUR_PROJECT_REF`
4. تابع را منتشر کن:
   `supabase functions deploy c90-admin-user`
5. در Supabase Dashboard → Edge Functions بررسی کن تابع `c90-admin-user` با موفقیت Deploy شده باشد. متغیرهای پیش‌فرض `SUPABASE_URL`، `SUPABASE_ANON_KEY` و `SUPABASE_SERVICE_ROLE_KEY` باید در محیط تابع موجود باشند. کلید service role را در HTML، GitHub یا مرورگر قرار نده.

## آزمون پس از انتشار

- با حساب مدیر وارد شو و یک حساب آزمایشی شرکت‌کننده را انتخاب کن.
- یک رمز آزمایشی جدید ثبت کن و ورود همان حساب را با رمز جدید بررسی کن.
- برای حذف، ابتدا یک حساب آزمایشی بساز؛ نام کاربری را در تأیید دوم وارد کن و مطمئن شو حساب و گزارش‌های آن حذف شده‌اند.
- حذف حساب مدیر باید از سمت RPC رد شود.

**توجه:** حذف حساب دائمی است و گزارش‌های روزانه همان حساب را نیز پاک می‌کند. برای آزمایش از حساب واقعی استفاده نکن.
